PIXEL → XYZ

1ピクセルの計算を動かす

以下は説明用の仮の値です。実装ではCameraInfoの投影行列Pから fx=P[0], fy=P[5], cx=P[2], cy=P[6] を読みます。

Z = Depth × 0.001 （16UC1：mm → m） X = (u − cx) × Z / fx Y = (v − cy) × Z / fy

例：640×480、fx=fy=500、cx=320、cy=240。32FC1の場合はDepthをそのままmとして扱います。

同じ画素のBGRを点群のRGBへ格納。距離0や不正値はNaNの点を残します。640×480なら307,200点の配置を保ちます。

READ THE CODE

混同しやすい4つの関係

  • 登録と実行：コンストラクタの registerCallback() は処理の予約。実際の呼び出しはspin中の受信・同期がきっかけです。
  • 圧縮展開とMat変換：image_transportが圧縮を解き、cv_bridgeが展開済みImageをOpenCVで扱えるようにします。
  • 時間同期と位置合わせ：ApproximateTimeは撮影時刻で組を作ります。DepthをRGBへ位置合わせする処理はこのコードにはありません。
  • 点群座標と表示視点：C++はカメラ座標の点群を作ります。RVizのFixed Frameの変換にはTFを使い、視点はマウスで操作できます。

出力がない場合の読み方

Received decoded RGB=… depth=… CameraInfo=… のどれかが0 → 購読・展開・配信を確認。全部増えるのに点群が0 → 同期のtimestampや検証ログを確認。点群数は増えるのにRVizが空 → topic・QoS・Fixed Frame・TF・視点を確認。
